# 侧边图注、跨栏图与提前加载（2026-11-01）

## 范围与原因

- W37N2YED 的图 10 横跨两栏，旧候选框沿用左栏正文宽度，截断右侧翼肋。
- 图 11、13、14 为左图注、右侧多行图。旧算法只查图注上下方，导致误取局部、页脚或空白。
- 原实现遍历所有视图管理图片内存，旧视图的 Gecko 失效对象会中断遍历；当前卡片已显示图片后也可能因此被改为错误。
  旧交付代码在真实 Gecko dead wrapper 上复现同类异常；这证明了该故障路径，不代表已还原用户每次关闭标签的操作序列。

## 实现

- 为靠页边的窄多行图注建立左右候选框；相邻侧图按下一图注顶部划分，正文占据相邻区域时禁止侧向取图。
- 当相邻栏在整个候选高度内没有正文、图注或图形阻挡时，允许短图注对应的图跨栏。
- 保留 Reader 原生区域渲染和像素修边，使用原 PDF 图形内容；不截整页，不按论文 ID 特判。
- 缓存算法键改为 `region-crops-2`，旧错误裁剪自然失效；缓存元数据允许左右方向，避免重开再次渲染。
- 自动预加载范围由 400 px 扩到上下各两屏，最少 1200、最多 3200 px；停稳等待由 160 改为 80 ms。
  可见及近处图优先；轮到渲染前再核对距离，跳过已经滚远的排队任务。保留分段扫描、串行原生渲染和估算内存预算。
- 内存卸载范围留在预取范围之外，避免提前载入后立即卸载。检测失效视图并清理，在异步返回后复核存活状态。
