# 原生图去重、混合裁剪块与完整阅读布局（2026-11-01）

## 验收缺口与实际根因

上一轮实际 PDF 用例使用了真实区域渲染，但把原生图和表格简化为空 DOM 节点。
因此成功载入补图不能证明“没有重复、原生图与补图顺序正确、整页布局正确”。
本轮改用安装版 Reader 的 SDT renderer、样式、区域提供器及原生图片 hydration 方法。

截图对应 Dogea 2023：

- 第 8 页图 10 的图注位于左侧，原生图片位于右侧。旧 36/48 pt 纵向距离与横向重叠规则漏掉关联。
- 同页 SDT 表格块包含图 11 照片、图 11 图注、表 5 图注及表体，整块被排到两个图注之后。
- W37N2YED 的原生图 6 实际分成两个图像块；仅找到其中一个不能代表完整图形。
- W37N2YED 的公式 18 源裁剪还包含下方流程图。分离流程图时必须保留公式。

## 本轮行为

- 原生块按同页位置、方向、无遮挡通道及竞争图注建立关联；区分普通缺失补图和原生区域替换。
- 普通原生图移到对应图注之前；侧边、残缺多子图重新规划完整区域，替换相关原生碎片。
- 原生图像块作为恢复依据时，不再把它本身当作阻挡物切断候选区域。多个相关子图一并处理。
- 单图/单表及整列多图/多表复合裁剪块，先完整规划全部成员再拆分：图形→原文图注→译文；表注和译文→表体。
- 公式误含图形时，用公式文本坐标保留公式区域，另显示图形。多图复合块不能安全完整拆分时保留原块。
- 同组所有替代图片都成功解码后才切换可见性。失败保留原生区域；关闭功能恢复原节点、位置和 hidden 状态。
- 仅译文模式隐藏原图注时，以尚可见的原生块判断预加载位置，避免替代区域一直等待。
- 缓存键改为 `region-crops-3`，不命中之前的错误裁剪；不删除原 PDF、SDT 或译文缓存。
- 短正文续句仍作为边界，侧图保留页边框内距以排除页脚；曲线图恢复完整图例及坐标标注。

仍采用本地几何规则；没有集成新的版面模型，也不代表所有复杂 PDF 均可无误识别。
