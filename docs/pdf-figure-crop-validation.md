# 1.6.12：单图区域提取与桌面报错修正

## 目标与工作区

根据用户反馈，把 1.6.11 的整页预览改为只补充单独图形。
工作分支仍为 `fix/toolbar-display-dropdown`，基于 PR #2 的
`1ab7450abca3ff8f0377aec2bca2764b92fc1e6d`；保留此前所有本地修改，未推送远程。
原 PDF、原始 SDT 缓存、已有译文缓存及 Zotero 安装文件均保持不变。

## 用户截图确认的两个错误

- `TypeError: item.target._zrbLoadPage is not a function`：加载函数挂在内容 DOM
  节点上，但观察器回调取得的节点包装无法读取该函数。改用模块内部 WeakMap
  保存节点与回调的映射，观察器选项也转换为目标文档所属环境中的普通对象。
- `page.getViewport is not a function`：插件从 PDF.js 跨环境取得的页面对象不具备
  原先假定的可用接口。移除插件直接获取页面、调用 getViewport/page.render 的
  路径，改用当前 Reader 的 `_pdfRenderer.renderRegionCrops()`；内部仍使用
  Zotero 自身的页面对象和字体环境。传入坐标在调用前转换到 Reader 环境。

这些结论限于截图显示的接口/包装失败，未进一步断言 Gecko 具体采用了哪一种
对象包装。其他插件的 WASM、缓存和 WebGL 日志没有作为本次缺图原因。

## 图形边界与显示逻辑

1. 找出有 Figure/Fig./图编号、页坐标，但没有相邻图形块的图题。
2. 从相邻正常正文推断单栏或通栏宽度。用正文、标题、公式、表格、其他图题与
   已有图形界定图题上方/下方区域；运行页眉页脚也用于限制边界。
3. 数值刻度和图例可能被 SDT 错分为 paragraph，因此根据词语比例、句子标点等
   特征区别叙述段落与图内标签，避免从曲线图中间切断。
4. 对候选区域调用 Zotero 区域渲染，支持位图与矢量图；扫描非白像素并去除空边。
   当至少两个已有图形一致表明图题位于图上/图下时，用该位置关系避免截到前一幅图。
5. 每个图题独立插入图形，同页多图不合并。只显示裁出的图形区域；不可靠或空白
   区域会显示阶段与错误原因，不退回整页预览。图内原始文字与水印保留。
6. 接近视口才加载，串行调用区域渲染，重试会重新计算失败任务。关闭视图后
   移除预览、断开观察器、忽略迟到结果；已经交给原生渲染器的任务由原生接口完成。
