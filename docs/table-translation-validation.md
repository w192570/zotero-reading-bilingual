## 实现范围

- 整表翻译卡片内，把标准 Markdown 表格和旧缓存的竖线分隔行渲染为语义 HTML 表格；表头与行标签明确，数值按列对齐。
- 窄窗口只在表格内部横向滚动，首列固定；字号跟随已有译文设置，长表头可换行。
- 仅在已标记的整表卡片中解析旧格式。所有行列数必须一致；公式、行内代码或转义符中的竖线不当作列分隔符。列数不一致的译文保留文本，不推断、补齐或丢弃数据。
- 原始译文与显示 DOM 分离；重排旧缓存不写回、不请求模型。编辑、复制继续使用原始文本。用户主动重译时保持整表请求，新响应按同一方式显示。
- 不修改原 PDF、SDT 或原图，也不调整现有原图的显隐规则。
