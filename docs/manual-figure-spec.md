# 手动裁剪／修正图片

## 目标与边界

按本次用户要求实现：原生图、自动补图及失败框统一右键入口，另提供悬停轻量按钮；独立于自动补图开关。操作打开来自原 PDF 的逐页预览，不创建或修改 Zotero 批注。选区按 PDF 坐标保存，支持调整、增删、排序和跨页。确认时不扫描内容或自动裁边，每个选区独立渲染、独立显示，全部解码成功且记录落盘后才替换。

原生图与图注关联仅在 SDT 来源关系唯一时默认采用；编辑器允许选择图注或原位置。无可靠图注时保留原图位置。预览始终列出具体可替换图片碎片，用户勾选确认；禁止隐藏正文、公式、表格、图注、译文、链接或整页。复合节点含这些内容时不将整个节点列为可隐藏图片。对 SDT 明确标为辅助文本、符合重复图内短标记格式且完整落入用户选区的节点，只在用户额外勾选后才替换；其相邻译文仅在来源文本完全匹配时一并隐藏。原 PDF、SDT、译文和用户批注不改写。

错误图块若覆盖选区之外的图注或正文，不能整个隐藏；系统用临时局部遮罩仅盖住已选中的原图像素，剩余区域仍显示。可单独恢复原来的遮罩样式。连续重裁时，新图先完成渲染和插入，旧图与旧记录再替换；插入失败则保留旧显示并回滚记录。

## 模块与数据

- `manual-figure-store.js`：原子写入独立修正记录，按文献标识与内容指纹隔离；与可清理 PNG 缓存分离。
- `manual-figures.js`：SDT 目标解析、准确区域渲染、PNG 缓存复用、事务替换、恢复与视图生命周期。
- `manual-figure-editor.js`：原页预览、鼠标框选及调整、坐标微调、逐页添加选区、排序、预览与替换范围确认。
- 沿用普通脚本全局对象模式。跨权限参数先变为 Reader 所属环境的对象；不把特权 options 对象传入 PDF.js。
- 记录包括 schema、文献 ID、PDF 指纹、SDT 结构签名、稳定图/图注定位、替换节点定位及按顺序排列的 `{pageIndex, rect}`。指纹或锚点不符则保留原显示。
- 使用已有 PNG 缓存，手动键包含指纹、选区坐标、页旋转和渲染预算；不调用自动裁边。
- 预览与选区渲染依赖本机 Reader `renderRegionCrops`，预览使用内容环境中的独立受限 renderer 配置，不修改实际 Reader 设置。一次修正最多 12 个选区，选区 PNG 总量受约 3 百万像素预算及 24 MiB 驻留估算限制；关闭释放 UI、图像、事件与迟到结果。

## 实施顺序

1. 检查当前安装版 Reader 区域选择、坐标换算与区域渲染源码；建立缺失功能/失败替换/多页的失败用例。
2. 实现记录存储、准确区域渲染和原位可恢复替换。
3. 实现统一入口和多选区编辑器，接入现有生命周期、模式和缓存。
4. 用本机 Reader/PDF.js、真实 Gecko 和实际 PDF 验证，完成包与副本一致性核对。
