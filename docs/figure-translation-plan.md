# 图内文字翻译：三种候选方案

保存日期：2026-11-10。

状态：讨论方案留档，用户要求暂不实现。当前只将设置中的“翻译表格与图块”改为“翻译表格”；不增加图像翻译、OCR、译文覆盖或图片生成功能。

## 当前能力与问题来源

插件能翻译独立图注，不能可靠翻译图内坐标轴、图例和架构标签。旧整表入口把所有原生区域裁剪当作表格，导致图中文字被强行组织成表格；当前修正版仅允许 HTML 表格及 SDT 明确标记的表格进入整表流程。

SDT 类型属于线索，不能当成绝对真值。图像翻译若后续实现，需要独立入口及用户纠正类型的能力，不能简单恢复旧的“所有区域裁剪均作为表格”逻辑。

## 方案一：图旁文字对照

保留原图，在图旁或图下展示逐条原文与译文。条目与原图中的文字位置关联，点击条目可高亮对应位置。对照列表只表示文字对应，不解释或重组原图结构。

- 优先获取原 PDF 选区内可靠的文字与位置；文本层缺失、乱码或字体编码有误时，对原 PDF 渲染的选区做 OCR。
- 每个文字条目分配稳定编号，按编号请求与接收译文，校验遗漏、重复和错位。
- 图像与图注可以作为术语上下文，模型只翻译已识别文字，不补写未出现的标签。
- OCR 原文和中文译文分别可编辑；只重试被修正的条目。
- 数字、单位、变量及公式默认保留；无法可靠识别时展示待核对状态。
- 碎片按来源坐标归并；跨页图按选区顺序分组，不混成一串文字。

优势：原图不被遮挡，容易核对，能复用现有裁剪与缓存模块。局限：阅读时需要在原图和对照区之间切换。建议作为第一阶段，但本次不实施。

## 方案二：图上交互译文

在原图上叠加独立、可关闭的 HTML/SVG 译文层。支持指向原文显示中文，以及显示全部译文；始终可查看原图。

- 文字框采用原 PDF 坐标或相对选区的归一化坐标，随缩放、页面旋转和重裁剪重新换算，不保存屏幕像素位置。
- 竖排、倾斜文字保留方向；定位不可靠时退回方案一。
- 中文过长时使用引出标注或侧边气泡，不无限缩小字号。
- 曲线、网格、云图和色标上的文字不直接用白块覆盖，避免遮住数据。
- 多页和多区域分别维护坐标映射，逻辑上共用一个翻译组。
- 允许调整译文位置；改变裁剪范围后，重新校验旧文字框是否仍可复用。

优势：读图直观，位置对应明确。局限：定位、遮挡、旋转与生命周期的实现及验收成本较高。建议在方案一的数据基础上增加，保留图旁对照回退。

## 方案三：生成中文版图片副本

生成可导出、可分享的中文版图片，原图保留，可预览、切换和恢复。

- 先识别并核对文字，再翻译，优先以确定性排版写入新副本。
- 只处理已确认的文字区域；复杂背景修补才考虑图像编辑模型。
- 不默认将整幅科研图交给生成模型自由重绘。
- 文字压住曲线、色标或几何边界且不能无损擦除时，保留英文并增加旁注。
- 核对数字、单位、子图编号、箭头和连接关系；检查允许编辑区域之外的像素变化。不能只依靠提示词保证科学内容不变。
- 公式、尺寸标注默认保留原始内容；跨页组合图分别生成区域副本，不强制拼成长图。
- 导出前检查中文字体、分辨率及可读性；失败保留原显示。

优势：得到可独立使用的中文版图片。局限：处理和核验成本最高，存在误改科学内容的风险。建议仅作为后续用户主动触发的高级功能。

## 三种方案共用的边界

| 情况 | 处理原则 |
|---|---|
| Zotero 把图标成表或把表标成图 | 统一“翻译此区域”入口，允许纠正为图片文字、表格或暂不处理；结合类型、图注、来源位置和实际内容判断 |
| 图表混合或跨块 | 允许拆分选区，不强制给整个复合块指定同一类型 |
| 无图注、原图区域不完整 | 手动框选原 PDF，不要求可靠图号，不只裁缩略图 |
| 文本层乱码、OCR 不确定 | 保留原图并允许修改识别结果；识别评分仅辅助筛选，阈值需在真实样本上确定 |
| PDF 或选区变化 | 以文献标识、PDF 指纹、选区及识别版本区分数据，旧结果匹配失败时不强套 |
| 清理可再生成图片缓存 | 保留用户确认的文字、译文及位置记录 |
| 模型请求失败、取消或关闭视图 | 原图保持可用，取消待执行任务，丢弃迟到显示结果，避免重复请求 |
| 原文、对照、仅译文模式 | 定义图像译文的显隐规则，始终提供查看原图和恢复入口 |

## 建议的后续顺序及验收

如果用户以后决定实施：先统一入口、类型纠正和方案一；再复用文字—位置—译文记录实现方案二；有明确导出需求后才做方案三。

使用实际载荷图、GINOT 架构图、扫描图及跨页组合图建立样本，包含官方类型标错、字体编码错误、旋转、长译文、公式数字混排和图表混合的情况。先验证识别和对应关系、数字公式保留、类型纠正、失败回退、重开恢复，再验证显示效果。

实现后需分别记录自动测试、匹配安装版 Reader/PDF.js 的实际 PDF 验证和 Windows Zotero 桌面验收；当前保存方案不代表这些功能已实现或已验收。
