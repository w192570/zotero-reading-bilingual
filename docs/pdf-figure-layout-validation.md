# 缺图区域定位的通用回归

更新：2026-10-17。候选版本仍为 1.6.13，未提交、推送或发布。

## 本次确认的根因

GFocal 第 4 页的 Figure 3 没有独立 SDT 图像块；SDT 的公式块 72
却覆盖了公式与下方图形的联合区域。公式文本坐标位于上方，图形在其下方。
旧定位器把整个公式框当成不可裁剪边界，因而返回空候选，触发
「未找到可靠的图形空白区域」。失败发生于定位阶段，尚未调用 Reader 区域渲染。
同页 Figure 2 也存在公式框横向合并相邻图形的问题。

这是提取结果与插件定位规则共同造成的兼容缺陷；不属于仅译文样式隐藏图片，
也不是本次 Reader 回载失败。不应依赖用户逐篇调参数。

## 修改边界

- 仅在公式框明显超过其有效文本坐标时，使用公式文本的包围框及留白作为裁剪边界。
  文本映射缺失、损坏或页码不匹配时，保留原边界；不改写 SDT。
- 相邻的 `(a)…(b)…` 子图标签保留在图中；独立的表题仍阻断区域。
- 同页、同编号、位置相邻且横向重叠的双语图题共享一个区域和补图入口。
  不合并不同编号的图题。
- 中文正文可用英文句点结束；识别其正文范围，避免按较窄图题宽度截断图形。
- `excluded` 不直接等同页眉。排除文字在不同页面相同高度重复，才作为页眉/页脚证据；
  边缘页码仍作边界。这样保留图内被错误排除的列标题。
- 现有图像距图题略超过旧固定间距时，检查最近图题关系，减少重复补图。

以上规则不包含论文标题、存储键、指定页码或指定图号。仍裁剪单图区域，
不以整页作为定位失败时的自动回退。原 PDF、SDT、译文和配置不重建、不删除。

## 验证结果

单元回归新增 9 项（当前共 58 项）。先观察旧规则失败，再验证修正后的边界；
覆盖误扩公式框、无效文本映射、子图/表题、原生图像匹配、双语图题和中文栏宽。
Firefox 真实输入 9 项、Gecko 权限与输入 4 项全部通过，无跳过。

使用本机 Zotero 10.0.6 配套 Reader/PDF.js，在实际 PDF 上得到：

| PDF | 实际补图数 | 重点验证 |
| --- | ---: | --- |
| Carneiro/Gamboa 翼肋论文 | 14 | 同页独立图及原有边界 |
| LRQ-Solver | 10 | 矢量图与坐标轴标签 |
| GFocal | 2 | 第 4 页 Figure 2、3 与误扩公式框 |
| DeepSDF | 5 | 相邻子图标签 |
| Domain Agnostic Fourier Neural Operators | 2 | 列标题和子图标签完整保留 |
| 卷积神经网络与松鼠优化算法的机翼优化论文 | 7 | 双语图题去重、中文正文范围 |

共 40 处补图成功载入；6 篇各自指定的目标区域通过边界检查，
对 GFocal、DeepSDF、DAFNO、中文论文的目标裁剪图另做了原页对照与人工视觉检查。
不将所有「载入成功」写成逐图人工审阅。三种显示状态与关闭重开通过；
实际 Gecko 系统/内容权限边界下，40 处冷渲染及热磁盘命中通过，
热读取无需再次渲染，关闭后插件估算内存释放。测试前后原文件哈希不变。
原先两篇论文的 24 张输出图与上一候选构建逐像素一致。

另对文库现有的 18 份 SDTPack 作只读几何审计，均匹配相应原 PDF 哈希。
226 个识别图题中，无法产生候选区域的图题从 11 个降到 0；
当前 126 个图题对应已有图像，100 个有候选区域。
合并相邻双语图题后为 221 组图题、95 组补图候选。
**这些是几何覆盖统计，不代表 18 篇所有图片已正确呈现或桌面验收通过。**

## 复现与证据

仓库测试不包含论文、用户缓存和本地路径。设置本地 `ZRB_PDF_CASES` 清单后运行：

```powershell
npm test
npm run test:browser
npm run test:pdf
npm run test:gecko
```

新增只读工具 `tools/audit-figure-layout.cjs`，使用官方 SDTPack 解码器：

```text
node tools/audit-figure-layout.cjs --storage <Zotero-storage> --sdt-module <官方解码器> --output <文库以外的报告.json>
```

本地证据在 `../.diagnostics/zotero-pdf-figures/layout-generalization/`：
`audit-before.json`、`audit-after.json`、`extra-red-tests.log`、`extra-green-tests.log`、
四类测试日志、`rendered/integration-results.json`、`rendered/gecko-results.json`、
`previous-24-comparison.json`、`build-result.json`、`delivery-check.json`。
诊断资料含本地文献信息，不随仓库或 XPI 分发。
