# Zotero 阅读模式沉浸式双语

专为 Zotero 阅读模式打造的中英双语对照翻译插件。译文以卡片形式插在原文段落之下，原文保持不动。

![version](https://img.shields.io/badge/version-1.7.0-blue) ![license](https://img.shields.io/badge/license-MIT-green)

![demo](docs/demo.gif)

> 左键点击工具栏的显示内容下拉框，即可选择「原文 / 对照 / 仅译文」。

## 效果

**段落对照**：译文卡片插在原文之下，原文一个字都不动。

![paragraph](docs/paragraph.png)

**目录整体翻译**：整页目录合成一张卡片，保留章节号、原标题与页码，跨页断开的目录会自动合并。

![toc](docs/toc.png)

**表格整体翻译**：整表译文显示为行列对齐的中文表格，宽表可横向滚动并固定首列。旧缓存无需重新翻译。

整表翻译只接受 HTML 表格或 SDT 明确标记的表格。图片、公式和类型未知的区域裁剪不进入该流程；历史上误生成的图片表格卡片会从视图移除，缓存保留但不再作为图片译文加载。图注继续按普通图注翻译。

![table](docs/table.png)

**设置**：Zotero 设置 → 沉浸式双语。

![settings](docs/settings.png)

## 功能

- **段落级对照**：正文按段成批翻译，译文卡片插在原文下方，可编辑、复制、单独删除。
- **三种显示状态**：工具栏直接显示下拉框，单击一次即可展开选择「原文」「对照」「仅译文」。「仅译文」隐藏已翻译的原文文字，同时保留图片、图表、公式与代码块；表格以中文译文卡片显示。原文段落中的行内代码随原文隐藏，独立代码块保留。
- **缺图区域补充**：PDF 阅读模式保留图题却没有相邻 SDT 图形块时，在图题前补充单独的图形。根据栏宽、图题和相邻正文定位区域，再调用 Zotero 的区域渲染接口，保留位图和矢量图；同页不同图分别显示。默认点击按钮后才加载；可在设置中的「PDF 图形补充」选择关闭或自动补图（滚动到附近时加载）。三种显示状态均可见，不需要清空 SDT 或译文缓存。边界无法确定时显示原因，供重试或回到 PDF 查看。
- **手动裁剪／修正图片**：原生图片、插件补图和失败框都可重新选区。裁剪直接从原 PDF 渲染，可添加多页、多区域，排序后预览；成功后再替换显示，可恢复原图或再次调整。修正记录在重进阅读模式和重启 Zotero 后仍可恢复；图片支持双击放大及拖动查看。
- **译文格式渲染**：保留换行，支持 Markdown 标题、强调、列表、表格与代码，以及 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 形式的 LaTeX 公式。新译文、已有缓存和编辑保存后的内容使用相同的渲染方式；编辑与复制保留原始 Markdown/LaTeX 源码。渲染库与字体随插件打包，无需联网下载。
- **目录整体翻译**：把整页目录识别成一个单元翻译成一张卡片，跨页断开的目录会自动合并，不会被切成几十条碎片。
- **表格整体翻译**：整张表作为一个单元翻译，译文按表头、行列对齐显示，宽表可横向滚动并固定首列。兼容已有竖线分隔的翻译缓存，编辑与复制保留原始译文；列数不一致时保留文本，避免自动补齐或丢失单元格。此项可在设置中关闭以节约额度。
- **并发翻译**：默认同时发出 3 个请求，可在设置中调到 1 到 8。长文献从逐个请求改为并发后耗时大幅下降；调太高会触发服务商限流，失败的段落可通过文献右键菜单再次翻译来补翻。
- **断点续翻**：每批译完立即写入缓存，中途关标签页、退出 Zotero 或断网都不会丢掉已经翻好的部分。通过文献右键菜单选择翻译只会补翻缺失和失败的段落，已完成的不会重复消耗额度。
- **阅读模式默认外观**：Zotero 自身没有页宽与字号的默认值设置，每篇文献打开都会回到 75%。插件可以代为设定，每篇文献进入阅读模式时应用一次。
- **跳过参考文献**：自动识别参考文献章节并跳过，不浪费额度。
- **本地缓存**：译文以 `<文献名>.bilingual.json` 存在附件同目录，重开秒级载入，不重复消耗 API。
- **多服务商**：Gemini、DeepSeek、SiliconFlow、OpenRouter、Moonshot、Qwen、OpenAI，以及任意 OpenAI 兼容接口。
- **排版可调**：字体、字号、行高、主题色、卡片底色、边栏线条样式。

## 安装

1. 从 GitHub Releases 下载已发布的 XPI；若要安装本开发分支的测试版，请按下方「开发」说明自行打包。
2. Zotero 菜单：工具 → 插件 → 右上角齿轮 → Install Plugin From File，选择该 xpi。
3. 打开一篇文献，**切换到阅读模式**，左键展开搜索图标左边的下拉框，选择「对照」或「仅译文」。已有译文会直接显示；首次使用会开始翻译。

> 请先打开 Zotero 自身的阅读模式，再选择显示状态。PDF 原始视图没有可供插入译文的段落结构。

## 配置

Zotero 设置 → 沉浸式双语。

插件**不自带任何 API Key**，需要自己填写。Gemini 可在 Google AI Studio 免费申请。填好后点「测试连接」拉取可用模型列表。

其余选项：主力模型、进入阅读模式时自动翻译、翻译表格、并发请求数、阅读模式默认页宽与字号、排版样式、自定义翻译提示词。

新安装时的译文样式默认使用典雅宋体、经典学术蓝、无指示线和微透浅底；已有的自定义设置仍以各设备本地保存的值为准。设置页的「恢复默认 Prompt」会使用当前版本内置的学术翻译提示词。

默认 Prompt 要求每段译文写在一行内，因此模型默认不会主动给一段译文加入换行；显示时仍会按卡片宽度自动折行。需要主动分行时，可以在卡片编辑框里按 Enter，或修改自定义 Prompt。此前已在缓存中被删除的换行无法自动恢复。无效或 KaTeX 不支持的 LaTeX 公式会保留源码。

关于并发请求数：默认 3 是速度与稳定的折中。免费额度的 Gemini 建议不超过 3，付费或高速率上限的接口可以调到 5 到 8。如果看到大量「[翻译失败: HTTP 429]」，说明超过了服务商的速率上限，调低即可，已经翻好的部分不会丢。

## 快捷操作

- 工具栏显示内容下拉框：单击一次展开「原文 / 对照 / 仅译文」，始终显示当前状态
- Ctrl/Cmd + Shift + H：切换原文与对照，下拉框同步更新
- Ctrl/Cmd + Shift + T 或工具菜单「重新翻译当前文献」：确认后清空缓存并重新翻译
- 正文中选中文本右键：只翻译选中部分

## 阅读模式默认页宽与字号

Zotero 的阅读模式「外观」面板里可以调页宽和字号，但这两个值只对当前打开的文献生效，关掉再开就回到内置默认的 75%。Zotero 没有提供对应的偏好设置，默认值写死在阅读器内部。

插件在设置里补了这两项：

- **默认页宽**：不修改 / 50% / 75% / 100%
- **默认字号**：不修改 / 100% 到 250%

选定后，每篇文献进入阅读模式时插件会应用一次。**之后你在「外观」面板里手动改动不会被抢回去**，当次阅读一直保持你手调的值。两项默认都是「不修改」，不设就完全不碰 Zotero 的行为。

## 关于云同步

译文缓存 `<文献名>.bilingual.json` 与附件同目录，是否会跟随 Zotero 同步取决于同步方式：

| 同步方式 | 附件类型 | 缓存是否上传 |
|---|---|---|
| Zotero 官方存储 | PDF / EPUB | 否，只上传附件本体 |
| Zotero 官方存储 | 网页快照 | 是，整个目录打包上传 |
| WebDAV（坚果云等） | PDF / EPUB | 不保证；仅缓存变化不会触发上传 |

两点需要注意：

1. Zotero 判断附件「是否有改动」只看附件本体的修改时间与哈希，不看目录里的其他文件。所以只有译文缓存变化时不会触发上传；即使用 WebDAV，也不能依靠它同步 PDF 旁边的缓存。
2. 从云端下载附件时 Zotero 会先清空该附件目录再解压，本地的译文缓存会被一并删除。重要的译文建议先用卡片上的「复制」按钮导出。

## 已知限制

- 自动补图依赖图题、版面位置和文字特征推断边界，复杂嵌套或跨页排版可能漏判；它不替代 Zotero SDT 提取器。定位不可靠时可用手动裁剪跨页添加多个区域。图形内部英文和 PDF 水印会保留。
- 1.6.11、1.6.12 的桌面失败记录与修复分别见验证文档。1.6.13 在进入补图模块时将 SDT 复制到插件环境，修正 Gecko 对跨环境数组回调的权限拒绝；新增真实系统权限与内容权限的回归测试。实际论文与随附渲染代码的测试仍不能代替 Windows Zotero 内安装复核。
- 仅支持阅读模式，不支持 PDF 原始视图与网页快照。
- 表格文字在阅读模式中已被拉平为一行，还原出的行列结构依赖模型推断，复杂表格可能不完全准确。
- 目录识别基于「章节号 + 标题 + 页码」的排版特征，非常规排版的目录可能识别不到，会退回逐条翻译。
- 纯中文模式会保留图表、图片中的原始文字；嵌入图形内部的英文标签无法单独隐藏或翻译。

## 手动裁剪／修正图片

在阅读模式中将鼠标移到原生图片、插件补图或失败框上，点轻量「裁剪」按钮；也可在图片上右键选择「裁剪／修正图片」。在原 PDF 页面预览中框选一个或多个区域，可以跨页添加、排序、调整和预览。新结果按区域顺序分别显示，确认后才替换原图；编辑器内可勾选需要隐藏的原图碎片，并选择图注上方或原位置。

手动修正会按文献和 PDF 指纹保存到 Zotero 数据目录中插件专属目录，和可清理的 PNG 缓存分开。重新打开阅读模式或重启 Zotero 后会按已保存选区恢复；右键修正图可重新裁剪或「恢复原显示」。不修改 PDF、SDT、原始译文，也不请求模型。

## 开发

无需构建步骤，仓库结构即插件结构。打包：

```bash
zip -r -X zotero-reading-bilingual.xpi manifest.json bootstrap.js prefs.js content
```

渲染与编辑回归检查：`npm ci && npm test`。首次运行浏览器回归前执行 `npx playwright install firefox`，再运行 `npm run test:browser`。浏览器用例使用 Firefox 的真实鼠标输入，并按 Zotero 焦点管理的规则取消普通工具栏控件的 `pointerdown` 默认行为；原生下拉框会被放行，测试会单击并实际选择状态。npm 依赖只用于测试，不参与插件运行。

实际 PDF 回归：设置 `ZRB_PDF_CASES` 为本地用例清单路径后运行 `npm run test:pdf`。清单格式为 `{ "pdfjs": "PDF.js资源目录", "readerBundle": "Zotero随附reader.js路径", "output": "结果目录", "cases": [{ "name": "用例名", "pdf": "原PDF路径", "sdt": "解包后的SDT JSON路径", "page": 4, "sourceRef": "73", "expectedRect": [330.7, 56.5, 544.3, 295.1], "preserve": ["原SDT二进制缓存路径", "译文缓存路径"] }] }`。`pdfjs` 下应包含 `build/pdf.mjs` 及匹配的 Worker；`sourceRef` 是 SDT 图题路径；`expectedRect` 是独立核对的图形边界，采用 PDF 坐标系。测试运行随附 Reader 的区域渲染代码，核对图形完整性、三态可见性及缓存不变；不联网请求翻译服务，不把论文或用户缓存纳入仓库。

当前未发布改动：补图设置位于「主力翻译模型与行为」之后、「排版美化」之前，默认「点击补图」。切换后对已打开的 PDF 阅读视图立即生效；手动与自动之间切换保留已载入图片，关闭时移除补图并清理其状态。自动失败会保留重试按钮，不随滚动反复重试。自动模式通过观察器、滚动事件和定期可见区域检查触发。

同组新增本地补图缓存开关、用量和清理按钮。默认缓存成功的单图 PNG，保存在 Zotero 数据目录下的插件专属 cache 目录，上限 128 MiB，按最近使用淘汰；关闭磁盘缓存后停止读写而不删除已有文件。内存采用 32 MiB 估算预算，优先保留可见图，远离视口卸载并保留布局，返回时恢复已读图。该预算不等于 Zotero 整体内存上限。清理不会改动 PDF、SDT、译文或当前显示的图。

自动补图会等滚动停稳后再启动新的原图渲染；像素扫描分段执行，PNG 编码异步完成，以减少首次补图对滚动的干扰。原生 PDF 渲染仍可能有短时停顿，尚未完成日常桌面手感复核。

补图定位另处理误扩的公式框、相邻子图标签、双语图题去重与中文正文范围。规则依据结构和坐标，不按论文单独配置；已用 6 篇实际 PDF 的 40 处补图回归，并对 18 份已有缓存作几何审计。几何审计不等于所有图像均已验收，日常 Windows Zotero 安装复核仍待完成。

阅读模式中的标题译文随原文标题层级自动加粗、放大；图注和表注译文居中，字号为普通译文的 85%。已有缓存译文直接应用，字号随译文字号设置缩放。

公式库加载使用插件提供的标准 `atob`，并显式绑定第三方库的导出作用域，避免 Gecko 中加载失败后原样显示数学标记。已验证 XPI 内的公式脚本、样式与字体加载；已有译文无需重译。

段落翻译失败后，可在卡片上点「重试本段」，或在正文顶部点「只重试失败段落」。重试先查缓存，再把仍缺失的段落分批请求；成功译文保留，错误占位不会当成有效译文保存。接口只返回部分段落时保留已完成结果，不把后面的译文错配到缺失位置。也可直接编辑失败卡片补写译文，无需请求模型。失败计数会显示在阅读区，不将部分失败报告为全部成功。

自动补图提前读取视口上下各约两屏（1200–3200 像素），停稳 80 毫秒后开始新的原图渲染，优先可见图并跳过已滚远的排队任务。支持页边多行图注左右补图，以及空闲相邻栏的跨栏图；原 PDF、SDT 与译文缓存不改写。

原生图像区域先与图注建立关联，避免重复追加；对于残缺子图、公式或表格误含照片的复合区域，安全拆分后再替换原生显示。同组图片全部成功解码才切换，失败保留原区域，关闭功能可恢复原生节点。原 PDF、SDT 和译文不改写。
